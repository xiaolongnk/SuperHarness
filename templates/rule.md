# Rule — template

> Copy to your rules directory (one rule per file). Rules load every session and fire
> automatically. The trigger scopes *when* a rule applies; the WHY is what makes it stick.
> Keep it short — always-on budget is scarce, every rule is paid for on every session.

---

```markdown
# <Short rule title — the one thing to remember>

**Applies when:** <the trigger — be specific about the situation that activates this rule>
e.g. "writing or editing any description string, docstring, or schema `description` field."

## Rule
State it in the present tense, as a fact about how things are done here. Imperative is fine.
- <the rule, in one or two crisp lines>
- e.g. "Describe what a thing IS and DOES. State it factually — not 'use this when you need…'."

## Why
The cost of NOT following it — the concrete failure this rule exists to prevent.
e.g. "Speculative 'use this when' descriptions drift out of date silently and mislead the next
agent into the wrong tool. A factual description stays true."
```

---

## Why each section exists

- **Applies when** scopes the rule. An always-on rule with no trigger is noise that fires on every
  task whether relevant or not; a sharp trigger keeps the rule cheap and the attention focused.
- **Rule** is the instruction itself — present-tense and factual so it reads as how things *are*,
  not a suggestion to consider.
- **Why** is the load-bearing part. A rule with a reason behind it survives; a bare "do X" gets
  rationalized away the first time it's inconvenient. The cost-of-not-following-it makes it stick.

## Tips

- **Keep it short.** Every rule is loaded every session; the always-on budget is small. If a rule
  needs more than a screen to explain, the detail belongs in a doc and the rule should point to it.
- **One rule per file.** Bundled rules get half-read and half-applied.
- **Promote a rule only after you've had to give the same correction twice.** A rule you write
  pre-emptively for a problem you've never hit is speculative weight — earn the rule with the scar.
- Delete rules that no longer apply. A stale rule fires forever until someone removes it.
