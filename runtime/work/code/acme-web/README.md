# acme-web (EXAMPLE)

> **This is a fictional example project**, shipped with the framework so a fresh clone has a
> real, work-tier project to route work against — see
> [`runtime/README.md`](../../../README.md) for why this exists and how to replace it with
> your own projects.

A stub for a customer-facing web app maintained by a multi-person team — a reports dashboard
and account-settings surface. This directory holds a single illustrative stub file
(`app.js`), not a working build; the point is to demonstrate the work-tier layout (registry
row, agent definition, task board), not to ship real frontend code.

## Why this is work tier

Multiple maintainers, real coordination cost — see [`docs/portfolio.md`](../../../../docs/portfolio.md)
§2 for the tier model. Changes here go through a feature branch and a PR, never straight to
`main`. See [`agents/acme-web.md`](../../../../agents/acme-web.md) for the full agent
definition and [`docs/tasks/acme-web.md`](../../../../docs/tasks/acme-web.md) for the task
board.
